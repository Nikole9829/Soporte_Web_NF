Puesta a punto

Configuración inicial y asistencia para dejar el equipo listo para volver a utilizarse.

Antes de formatear, respalda tus archivos importantes. El respaldo de datos y las licencias del sistema no se incluyen salvo acuerdo previo.

¿Cuándo puede servir?

  • Cuando el sistema presenta errores persistentes.
  • Si necesitas reinstalar y configurar el sistema operativo.
  • Para preparar el equipo para un nuevo uso, previa revisión de compatibilidad.

Qué tener en cuenta

  • Haz una copia de seguridad de documentos, fotos y archivos importantes.
  • El sistema y los controladores dependen de la compatibilidad del equipo.
  • Licencias, repuestos y trabajos adicionales se cotizan o acuerdan por separado.
